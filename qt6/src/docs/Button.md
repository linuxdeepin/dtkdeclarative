# Button 普通文本按钮样式参考

本文档说明普通文本按钮（非选中、非高亮）的渲染方式：在不同主题、不同控件状态、不同窗口模式下，按钮分别由哪些元素构成、每个元素在什么条件下出现、以及它呈现什么颜色与状态。阅读本文档后，开发者应能据此写出对应的渲染条件代码；精确色值以 [FlowStyle.qml](../qml/FlowStyle.qml) 为准。

源文件：[Button.qml](../qml/Button.qml)、[ButtonPanel.qml](../qml/private/ButtonPanel.qml)、[BoxPanel.qml](../qml/BoxPanel.qml)、[FlowStyle.qml](../qml/FlowStyle.qml)

---

## 三个维度

按钮的样式由三个维度共同决定：

- **主题**：亮色 / 暗色
- **控件状态**：普通 / 悬浮 / 按下 / 未激活 / 禁用
- **窗口模式**：普通模式（不透明窗口）/ 水晶模式（半透明毛玻璃窗口）

**颜色回退规则**（用自然语言表述，供编写代码时参照）：

1. 暗色主题下，若某个状态没有单独定义暗色取值，则使用亮色对应状态的取值，并把红、绿、蓝三个通道取反（透明度保持不变）。系统高亮色（Highlight）会自动适配主题，不做取反。
2. 同一主题内，若没有单独定义悬浮 / 按下等状态，则回退到普通状态的取值。
3. 水晶模式下，若没有单独定义水晶专属取值，则回退到普通模式的取值。
4. 若某个元素的颜色未定义或为透明，则该元素不渲染。

> 未激活状态一般与普通状态表现一致，唯一例外是「水晶亮色毛玻璃」：在亮色主题下，未激活状态不显示毛玻璃（见下文）。

## 阴影总开关

按钮的外投影与内阴影受一个总开关控制：

- **普通模式**（亮色、暗色）：开启。
- **水晶模式 + 暗色主题**：开启。
- **水晶模式 + 亮色主题**：关闭。此时按钮不渲染任何外投影和内阴影，只显示背景、毛玻璃和外边框。

总开关开启时，各阴影是否最终显示，还要看其颜色是否为透明（见下文各元素说明）。内斜面是水晶暗色专用的内阴影形式，按下时单独关闭。

## 渲染元素与显示条件

### 远阴影（主外投影）

按钮向下的一层柔和外投影，模糊 1px、向下偏移 1px。

- **普通模式 + 亮色**：普通、悬浮状态显示一条很淡的下投影；按下状态投影加深；禁用状态回退普通状态取值。
- **普通模式 + 暗色**：普通、悬浮状态不显示（阴影色透明）；按下状态显示一条较深的下投影；禁用状态不显示。
- **水晶 + 亮色**：阴影总开关关闭，不显示。
- **水晶 + 暗色**：阴影色为透明，不显示。

### 近阴影（第二层外投影）

叠加在远阴影下方的第二层外投影，模糊 1px、向下偏移 2px；按下时偏移归零而关闭。

- **普通模式 + 亮色**：普通、悬浮状态显示淡下投影；按下状态关闭；禁用状态回退普通状态取值。
- **普通模式 + 暗色**：阴影色透明，各状态均不显示。
- **水晶模式**：阴影总开关关闭或阴影色透明，不显示。

### 内阴影（普通模式专用）

普通模式下按钮有两道内嵌阴影，用于营造立体边缘：顶部内阴影（向上偏移 1px）与底部内阴影（向下偏移 1px）。水晶暗色改用「内斜面」，此处不渲染。

- **普通模式 + 亮色**：
  - 顶部内阴影：各状态均透明，不显示。
  - 底部内阴影：普通状态为明显白色高光，悬浮状态减弱，按下状态透明不显示，禁用回退普通状态。
- **普通模式 + 暗色**：
  - 顶部内阴影：普通状态为淡黑色，悬浮加深，按下透明不显示，禁用回退普通状态。
  - 底部内阴影：各状态均为很淡的白色。
- **水晶 + 亮色**：阴影总开关关闭，不显示。
- **水晶 + 暗色**：改用内斜面，此处不显示。

### 内斜面（水晶暗色专用）

仅在「水晶模式 + 暗色主题 + 非按下」时出现，由一白一黑两道内嵌阴影组成，分别位于按钮边缘上下，形成立体凸起感。按下时关闭，只显示背景与毛玻璃；禁用、未激活状态下仍保留（按非悬浮取值）。

- 白色内斜面：普通 / 未激活 / 禁用状态为淡白色，悬浮加深。
- 黑色内斜面：普通 / 未激活 / 禁用状态为黑色，悬浮加深。

### 水晶毛玻璃

仅在水晶模式下出现的背景模糊效果（模糊半径 15、饱和度 1.0），形成毛玻璃质感。

- **水晶 + 亮色**：普通、悬浮、按下状态显示；未激活、禁用状态不显示。
- **水晶 + 暗色**：普通、悬浮、按下、未激活状态显示；禁用状态不显示。
- **普通模式**：不显示。

### 背景渐变

按钮背景为从上到下的垂直渐变（上色到下色），两色不同时才显示。

- **普通模式 + 亮色**：普通、按下状态有渐变；悬浮状态两色相同，无渐变。
- **普通模式 + 暗色**：普通、悬浮状态有渐变；按下状态两色相同，无渐变。
- **水晶模式**：各状态两色相同，无渐变。

### 外边框

按钮外缘的 1px 描边。

- **普通模式 + 亮色**：各状态均显示，悬浮与按下时略加深，禁用回退普通状态。
- **普通模式 + 暗色**：普通、悬浮、禁用状态显示；按下状态透明不显示。
- **水晶 + 亮色**：仅悬浮状态显示，其余状态透明。
- **水晶 + 暗色**：各状态透明，不显示。

### 文字

- **普通模式 + 亮色**：普通状态为半透明黑色，悬浮状态为不透明黑色，按下回退普通状态。
- **普通模式 + 暗色**：取亮色取值并反色，普通 / 按下为半透明白色，悬浮为不透明白色。
- **水晶 + 亮色**：与普通模式亮色相同；按下状态文字变为系统高亮色。
- **水晶 + 暗色**：取亮色取值并反色，普通为半透明白色，悬浮为不透明白色；按下状态文字变为系统高亮色（高亮色不反色，自动适配主题）。
- **禁用状态**：各模式均回退普通状态取值。

### 整体透明度

任意模式下，禁用状态整体透明度降为 40%，其余状态为 100%。

## 固定布局参数

| 参数 | 值 | 说明 |
|---|---|---|
| 圆角 | 6 | `Style.button.radius` |
| 边框宽度 | 1 | `Style.control.borderWidth` |
| 水平内边距 | 6 | `Style.button.hPadding`（等于圆角） |
| 垂直内边距 | 3 | `Style.button.vPadding`（等于圆角的一半） |
| 图标尺寸 | 24 | `Style.button.iconSize` |
| 宽 / 高 | 140 / 36 | `Style.button.width` / `height` |
| 四边内缩 | 1px | 为外边框预留，避免被父级裁切 |
| 毛玻璃半径 | 15 | `InWindowBlur` |
| 毛玻璃饱和度 | 1.0 | `InWindowBlur` |
